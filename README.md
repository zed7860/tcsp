# tcsp

A lightweight static website, ready to deploy on Vercel.

## Deploy

1. Import this repository in [Vercel](https://vercel.com/new).
2. Keep the project root as the root directory.
3. Select **Other** as the framework preset, leave the build command empty, and set the output directory to `.`.
4. Deploy. Vercel serves `index.html` directly; no build step or dependencies are required.
